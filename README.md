# Stocks

App hors ligne de contrôle des stocks (sac d'évacuation + maison).

Adresse : https://gg59fr.github.io/stocks/

Sur iPhone : ouvrir l'adresse dans Safari → Partager → « Sur l'écran d'accueil ».
Les données restent sur le téléphone. Sauvegarde mensuelle conseillée (bouton « Sauvegarder dans Fichiers »).
